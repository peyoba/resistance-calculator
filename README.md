# 电阻组合计算器

一个用于开关电源反馈分压电阻选型的网页小工具。单文件实现，无依赖，浏览器直接打开 `index.html` 即可使用。

## 功能

| 位置 | 按钮 | 公式 | 说明 |
|---|---|---|---|
| 顶部 | 无电阻并联组合 | `Vout = VFB × (1 + R1/R2)` | 单电阻组合，保留略高于 Vout 的结果 |
| 顶部 | 有电阻并联组合 | 同上 | R1 / R2 可由两个电阻并联构成，最多显示 100 组 |
| 左侧 | 无电阻并联组合 | `Vout = VCC × R2/(R1+R2)` | 单电阻分压 |
| 左侧 | 有电阻并联组合 | 同上 | 并联组合，最多显示 100 组 |
| 右侧 | 搜索阻值 | 并联等效阻值 | 查找略低于目标阻值的组合，无结果显示 `srooy!` |

## 使用说明

- **顶部**：已知芯片反馈基准电压 VFB 与目标输出电压 Vout（单位 V），按输出精度（mV）搜索分压电阻组合。
- **左侧**：已知供电电压 VCC 与目标输出电压 Vout，按精度（mV）搜索分压电阻组合。
- **右侧**：输入所需阻值与容差（Ω），在两个电阻的并联组合中查找等效阻值。

结果行格式为 `R1_0 / R1_1 / R2_0 / R2_1 / 输出值`；`0000` 表示该支路为单个电阻，两值并列表示两电阻并联。

## 电阻库

内置 77 个常用精密阻值（100 Ω ～ 910 kΩ），覆盖常用 1% 系列档位。

## 目录结构

- `index.html` — 页面、样式与全部计算逻辑。
- `assets/circuit.png` — 分压电路示意图。

## 开发

纯原生 HTML / CSS / JavaScript，无构建步骤、无第三方依赖，修改后刷新浏览器即可生效。
